Hi my name is Tommy Rutting, i'm a producer, DJ and sound & video engineer and i programmed a Roland TR-808 Rhythm Composer in Pure Data, no AI/Vibe coding, all hand build.
All sounds made with synthesis as much as the original works, no samples.
I tried to get as close to the original as possible, still tweaking, but sounds are pretty close.
Not all functions are active, accent, second pattern, basic variation, pre scale and fill in are not yet made.
Still have to implement DAW project automatic saving.
Pattern programming does work like on the original.
Still in working on it, so quirks are present.
