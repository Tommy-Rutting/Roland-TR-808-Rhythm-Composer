Hi my name is Tommy Rutting, i'm a producer, DJ and audio & video engineer next to UNIX/LINUX system administration, and i programmed a Roland TR-808 Rhythm Composer in Pure Data, no AI/Vibe coding, all hand build. Install Plugdata v0.9.3 or higher https://plugdata.org/download.html and open de pd file. Run in presentation mode to keep the faceplate save, when it happens just undo your action and switch to presentation mode. All sounds made with synthesis as much as the original works, no samples. I tried to get as close to the original as possible, still tweaking, but sounds are pretty close. Not all functions are active, accent, second pattern, basic variation, pre scale and fill in are not yet made. Still have to implement DAW project automatic saving. Pattern programming does work like on the original. Work in progress, so quirks are present.
